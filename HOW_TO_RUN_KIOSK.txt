====================================================================
      HEAVENOS - SANDBOXED DESKTOP WITH HOT APP INSTALLER
====================================================================

FEATURES:
1. Normal Desktop & Window Experience:
   - Window minimize, maximize, close bilkul normal kaam karte hain.
   - Screen ke bottom par ek sleek glass dock/taskbar hai — jab app minimize
     hogi, toh dock par icon click karke user wapis open kar sakta hai!
2. Strict Security & Sandboxing:
   - Terminal is COMPLETELY DISABLED (Ctrl+Alt+T ya terminal commands blocked).
   - Desktop par Right-Click completely disabled hai (kuch open nahi ho sakta).
   - Default app: Sirf Google Chrome chalta hai.
3. Hot In-Session App Installer (Without Terminating):
   - Agar session chal raha hai aur user/worker ko koi aur app chahiye,
     toh terminal me simply command chalao:
     bash add_app.sh blender
     --> Blender download hoke bina session restart kiye direct live screen pe launch ho jayega!

--------------------------------------------------------------------
STEP 1: CLEANUP OLD SESSIONS
--------------------------------------------------------------------
docker rm -f $(docker ps -aq) 2>/dev/null ; pkill -f cloudflared 2>/dev/null ; rm -rf heaven-os-Experimental

--------------------------------------------------------------------
STEP 2: FRESH CLONE & START
--------------------------------------------------------------------
git clone https://github.com/rowhanissick/heaven-os-Experimental.git && cd heaven-os-Experimental && bash start_kiosk.sh

--------------------------------------------------------------------
STEP 3: CLOUDFLARE PUBLIC LINK
--------------------------------------------------------------------
curl -sL --output cloudflared https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64 && chmod +x cloudflared && ./cloudflared tunnel --url http://localhost:8888

--------------------------------------------------------------------
STEP 4: LIVE APP ADD KARO (Bina Session Band Kiye)
--------------------------------------------------------------------
Terminal me bas ye command run karo:
   bash add_app.sh blender
   bash add_app.sh discord
   bash add_app.sh vscode
