====================================================================
      HEAVENOS KIOSK - SMART WINDOW GUARD & TERMINAL LOCK
====================================================================

RULES & BEHAVIOR:
1. Normal Window Controls:
   - Window ke upar Minimize (_), Maximize ([]), aur Close (X) buttons dikhenge!
2. Smart Minimize Guard (Zero Desktop Access):
   - User minimize kar sakta hai, LEKIN hamesha kam se kam 1 app screen par rahegi!
   - Agar dono apps ko minimize karne ki koshish ki, toh system desktop kabhi nahi
     dikhayega — dusri app turant un-minimize ho kar screen occupy kar legi!
3. Terminal Disabled:
   - Terminals (xfce4-terminal, xterm) ko normal sessions ke liye completely disable/lock
     kar diya gaya hai.
   - Ctrl+Alt+T ya koi shortcut kaam nahi karega.
4. App Switching:
   - User "Ctrl + Tab" ya "Alt + Tab" se bhi apps switch kar sakta hai.

--------------------------------------------------------------------
RUN COMMANDS (Google Cloud Shell):
--------------------------------------------------------------------
1. Blender + Chrome Session:
   bash start_kiosk.sh blender chrome

2. Single App Session:
   bash start_kiosk.sh chrome

3. Public Web Link:
   curl -sL --output cloudflared https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64 && chmod +x cloudflared && ./cloudflared tunnel --url http://localhost:8888
