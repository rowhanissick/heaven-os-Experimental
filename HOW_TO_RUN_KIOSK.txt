====================================================================
      HEAVENOS KIOSK MODE - SINGLE & DUAL APP LOCKED SYSTEM
====================================================================

FEATURES:
- Full Locked Access: Zero Desktop, Zero Dock, Zero Taskbar, Zero Escape.
- Anti-Minimize: Minimize button disabled; auto-restores if clicked.
- On-Demand Download: Sirf wahi apps download hongi jo command me doge!
- App Switcher: Agar 2 apps run kar rahe ho, toh "Ctrl + Tab" (ya "Alt + Tab")
  daba kar dono apps ke beech switch kar sakte ho!

--------------------------------------------------------------------
EXAMPLES:
--------------------------------------------------------------------

1. DUAL APP MODE (e.g. Blender + Chrome):
   bash start_kiosk.sh blender chrome
   --> User "Ctrl + Tab" dabakar Blender aur Chrome me switch karega.

2. DUAL APP MODE (e.g. VS Code + Chrome):
   bash start_kiosk.sh vscode chrome

3. DUAL APP MODE (e.g. Discord + Chrome):
   bash start_kiosk.sh discord chrome

4. SINGLE APP MODE:
   bash start_kiosk.sh blender
   bash start_kiosk.sh chrome
