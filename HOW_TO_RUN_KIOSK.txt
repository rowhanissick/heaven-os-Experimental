====================================================================
      HEAVENOS KIOSK MODE - GOOGLE CHROME (LOCKED ACCESS)
====================================================================

NOTE: Yeh experimental version hai jisme:
- Koi Desktop ya Taskbar/Dock nahi hai
- Minimize button completely disabled / removed hai
- Sirf Google Chrome chalega Fullscreen me
- User agar Chrome band bhi karega toh watchdog use 1 second me auto-restart kar dega

--------------------------------------------------------------------
STEP 1: GOOGLE CLOUD SHELL ME FOLDER UPLOAD / CLONE KARO
--------------------------------------------------------------------
1. Google Cloud Shell terminal open karo (https://console.cloud.google.com/)
2. Is folder (HeavenOS-Kiosk) ko GitHub repo se clone karo ya direct Cloud Shell me paste karo:
   cd HeavenOS-Kiosk

--------------------------------------------------------------------
STEP 2: RUN KIOSK CONTAINER
--------------------------------------------------------------------
Command chalao:
   bash start_kiosk.sh

Container build ho kar Port 8888 par start ho jayega!

--------------------------------------------------------------------
STEP 3: CLOUDFLARE PUBLIC LINK GENERATE KARO
--------------------------------------------------------------------
Terminal me command chalao:
   curl -sL --output cloudflared https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64 && chmod +x cloudflared && ./cloudflared tunnel --url http://localhost:8888

Output me https://xxxx.trycloudflare.com link milegi.
Browser me link open karte hi direct Google Chrome samne hoga, bina kisi desktop ya minimize button ke!

--------------------------------------------------------------------
STEP 4: CONTAINER STOP KARNA
--------------------------------------------------------------------
Terminal me command chalao:
   bash stop_kiosk.sh
